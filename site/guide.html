Start in your project.

Free cloud models or local models. Choose what works for you.

Install OliveCode

Copy the command for your computer from the installation page. The installer checks your architecture and verifies the package checksum. It installs to your user account without administrator access.

olivecode ↓

This is an unpublished preview. Windows packages still need testing on Windows. Linux packages are not published.

Open a project

Open Terminal on macOS or PowerShell on Windows. Go to your project folder and run olivecode. On macOS, open a new terminal after installation so the command is available.

Choose a model

Cloud connects your own free provider account. Provider limits still apply. Local helps you choose and download an Ollama model for your computer. Downloads use disk space and may take time.

Let models help each other

Assist offers Teamwork for another perspective and Follow-through for a result check. Both can be switched off. Expand a completed answer’s work details to see what happened.

Use websites and Mac apps

Open /computer in OliveCode. Visible control uses the real mouse and keyboard, with smooth pointer movement and visible typing for short text. Background browser uses a separate browser without taking your mouse. Background Mac requires an isolated macOS VM or second Mac and remains a setup-required preview. Native Windows app control is not available yet.

Connect your phone

Open /remote in OliveCode. Create your own Telegram bot with BotFather, enter its token locally, and pair your private account using the setup code. Start Remote from your project folder and choose Coding, Mac apps + browser, or Background browser. Send a task to your bot; approvals and results appear in that private chat.

olivecode remote setup
olivecode remote start

Approve once, or for 90 minutes

Allow for 90 min approves permitted operations in the current project and mode. It can include commands and file changes. Captures still ask separately. Use /lock to cancel timed approval or /stop to stop the task. Changing modes or restarting also cancels the timer. Only the paired account can control the bot; Telegram bot chats are not end-to-end encrypted.

Keep your computer available

Leave your computer on, awake and online with the Remote terminal running. It is not an always-on cloud service. /status shows the connection and approval time. Ctrl+C in the Remote terminal disconnects and stops active work. Your pairing is retained for the next start.
