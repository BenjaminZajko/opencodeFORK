How free cloud models work

Connect your own account through Cloud in OliveCode. The app shows eligible free models from connected providers. Availability, model names and provider offers can change; the in-app list is the place to check what is available to you now.

OliveCode does not sell a subscription or model credits. A provider may still require an account, set a request quota, restrict availability or change its free offer. OliveCode does not include paid-only models or promise free access to every leading proprietary model.

What happens when a provider reaches its limit?

OliveCode tries another eligible, available free model from your connected providers. This helps you continue when an alternative is available. If all eligible cloud options are unavailable, you may need to wait for a provider reset, connect another free provider or choose a local model.

Automatic switching is a fallback, not an unlimited cloud service. Different models can produce different results. Review the model shown for each completed answer and check generated work before using it.

Local coding models through Ollama

Follow the step-by-step local coding guide ↗

Open Local or type /local. OliveCode checks the computer’s hardware and estimates a model memory budget, then offers model choices suited to different sizes and capabilities. The estimate is guidance, not a guarantee: other apps, model context and runtime memory use affect what will fit.

Models are downloaded through Ollama and use disk space. A downloaded local model runs inference on your computer without a cloud-model request quota. Your RAM, storage and processor set practical limits. Downloads, provider connections, browser tasks and other online tools can still need an internet connection.

Use Delete models in the Local menu to manage installed models. Ollama’s default model folder is ~/.ollama/models on macOS, /usr/share/ollama/.ollama/models for the standard Linux service, and %USERPROFILE%\.ollama\models on Windows; an OLLAMA_MODELS override or a different Ollama service account can change it. See Ollama’s storage documentation.
