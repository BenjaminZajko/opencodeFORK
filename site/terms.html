OliveCode is a free terminal coding agent. You stay responsible for the work you approve.

Using OliveCode

OliveCode can read and edit your project files, run approved tools, and use connected cloud or local models. Review permissions and results, keep backups and check generated changes before relying on them. AI output can be incomplete or incorrect. Do not use the app for unlawful activity or to access systems without permission.

Free software and provider limits

OliveCode has no subscription or credit balance of its own. Cloud providers still set their own availability, quotas, eligibility and terms. Automatic switching needs another eligible available model and can stop when none is available. Local models require suitable hardware and disk space. Optional external services, including WhatsApp Business, may have their own charges.

Computer and remote control

Visible Mac control shares your mouse and keyboard. Background browser controls a separate browser. Background Mac is a setup-required preview using an isolated Mac or virtual machine. Native Windows app control is not available. Keep remote access limited to your own paired account, review operations, and use Stop or /lock when needed. No permission grant makes every action safe or guarantees successful completion.
