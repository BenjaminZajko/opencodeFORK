More room to build.

OliveCode brings free cloud models, local models and coding tools into your terminal.

The project

Start in a project folder, connect your own provider account or choose a local Ollama model, and describe what you want to build. Assist adds planning and result reviews. Optional Computer and Remote modes extend the work to supported websites and Mac apps.

Contact

Support, sponsorships and privacy enquiries: olivecode.ai@gmail.com. Never send passwords or API keys. Bug reports and source code are available in the GitHub repository.

Built on open source

OliveCode is derived from OpenCode and includes third-party open-source components. The applicable license and notices are distributed with the app and available in the repository. Product names and comparison icons identify their respective owners.
